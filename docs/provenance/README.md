# Provenance records

Records carried over unchanged from the reproduction package prepared for the authors on 1 October 2026.
File paths inside them refer to that package's layout (`release_candidate_20260930/` corresponds to
`src/`, `release_data_REVIEW_ONLY_20261001/` to `data/`), and their status fields describe the package
before public release.

| File | Content |
| --- | --- |
| `frozen_module_manifest.json` | SHA-256 of the numerical modules used for the reported experiments (`src/code/`) |
| `original_tested_environment.json` | Python and package versions of the original experiment environment |
| `original_portable_checks.json` | Checks executed when the package was prepared |
| `original_data_notice.json` | Description and hashes of the exported inputs, including the bitwise-equality check against the original formal inputs |
